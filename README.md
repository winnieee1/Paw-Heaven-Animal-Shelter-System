# Paw Heaven Animal Shelter System

## Overview

Paw Heaven Animal Shelter System is a database project developed using Oracle SQL to organize and manage animal shelter records.

The database covers information related to animals, adopters, caretakers, veterinary checkups, and medication records.

## Database Components

The database includes the following entities:

- **Animal & Species** – Animal records and species information.
- **Adopter** – Information about potential adopters.
- **Caretaker & OnDutyCaretaker** – Caretaker information and duty assignments.
- **Vet** – Veterinarian information.
- **HealthCheckup** – Animal health checkup records.
- **Medication & Prescription** – Medication and prescription records.
